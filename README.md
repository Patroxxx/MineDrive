# MineDrive

**MineDrive** is a fork of MineGIT that replaces GitHub integration with Google Drive support, allowing players to store and manage their Minecraft worlds directly through Google Drive instead of using GitHub repositories.

The goal of this project is to make cloud saving and synchronization simpler and more accessible for users who already rely on Google Drive for storage and backups. MineDrive keeps the original idea of MineGIT while adapting it to a different platform and workflow.

# Dependencies

_**Bold** = Required_

- **Fabric API**
- Mod Menu

# Open Source

**MineDrive** is now fully Open Source!

The entire source code is publicly available, which means anyone can inspect, modify, and contribute to the project. Suggestions, improvements, and community contributions are always welcome.

## Important

Although the project is open source, **MineDrive** relies on a private client secret stored securely on a remote server and not included in the repository. Because of this, simply modifying the source code and compiling it yourself will not fully replicate the official functionality.
