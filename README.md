# MineDrive

**MineDrive** is a fork of MineGIT that replaces GitHub integration with Google Drive support, allowing players to store and manage their Minecraft worlds directly through Google Drive instead of using GitHub repositories.

The goal of this project is to make cloud saving and synchronization simpler and more accessible for users who already rely on Google Drive for storage and backups. MineDrive keeps the original idea of MineGIT while adapting it to a different platform and workflow.

# Requirements

_**Bold** = Required_

- **Fabric API**
- Mod Menu

# About Open Source

Hey! If you came here from Minecraft, Modrinth, or anywhere else looking for the source code, you probably noticed that the MineDrive source isn't here. It's not because I don't want to share it or because I'm trying to keep it private for no reason. The current version contains secret keys and sensitive Google OAuth information, and publishing it would completely destroy my API usage limits.

I'm currently trying to make a safe version of the project that can be published publicly without exposing anything important. But since I also have school and other projects to work on, it might take a while before that version is ready. If I manage to finish it, I'll definitely publish it here.

## BY THE WAY

The source code currently in this repository is from the original MineGIT project, not the MineDrive version, so trying to compile it won't give you MineDrive ._.
